How it runs

  1. 08:00 — check for due follow-ups and process up to three.
  2. Every 15 minutes, 09:00–16:30 — check the next eligible organization and send at most one email.
  3. Every send — check written consent, approval, opt-out state, daily limit and send history.
  4. Failures — record the error and add a dashboard notification.
This uses Cloudflare's built-in scheduled Worker event. It does not require a third-party scheduling service or a continuously running server.
